01 // PLUGIN INFORMATION

Engineered for predictable tick times.

Instead of blindly wiping ground items or breaking redstone contraptions, KZOptimizer targets the actual root causes of main-thread stalls.

01

Adaptive Entity Activation

Dynamically scales mob AI tick rates and pathfinding calculations based on player proximity, line-of-sight, and real-time MSPT headroom.

02

Dynamic View & Simulation Distance

Automatically adjusts per-world simulation and view distances during player surges so the server never drops below 20 TPS.

03

Non-Destructive Item & XP Merging

Consolidates nearby dropped entities and experience orbs into single packets with configurable radius limits—preserving farm output without clear-lag frustration.

04

Hopper & Redstone Tick Mitigation

Eliminates redundant inventory transfer checks on full containers and caches block-state lookups in dense technical farms.

05

Chunk Unload & GC Guard

Prevents sudden I/O freezes by pacing inactive chunk unloads across multiple ticks and avoiding forced synchronous garbage collection pauses.

06

Built-in Profiler & Spike Alerts

Identifies lag-heavy chunks, entity clusters, and misbehaving plugins in real time with actionable console and Discord webhook reports.

Supported Platforms Paper, Purpur, Pufferfish, Gale, Folia (Spigot supported with reduced async features)

02 // SERVER OPTIMIZATION GUIDE

Recommended Server Configuration

Pair KZOptimizer with properly tuned JVM flags and server files for maximum stability under heavy player load.

Aikar's / Generational ZGC Startup Flags

Prevents stop-the-world GC lag spikes when heap allocation exceeds 8 GB.

java -Xms10G -Xmx10G -XX:+UseG1GC -XX:+ParallelRefProcEnabled \
-XX:MaxGCPauseMillis=200 -XX:+UnlockExperimentalVMOptions \
-XX:+DisableExplicitGC -XX:+AlwaysPreTouch \
-XX:G1NewSizePercent=30 -XX:G1MaxNewSizePercent=40 \
-XX:G1HeapRegionSize=8M -XX:G1ReservePercent=20 \
-XX:G1HeapWastePercent=5 -XX:G1MixedGCCountTarget=4 \
-XX:InitiatingHeapOccupancyPercent=15 \
-XX:G1MixedGCLiveThresholdPercent=90 \
-XX:SurvivorRatio=32 -XX:+PerfDisableSharedMem \
-XX:MaxTenuringThreshold=1 -jar server.jar --nogui

config/paper-world-defaults.yml

Reduces redundant entity collisions, anti-xray overhead, and chunk save stalls.

chunks:
  auto-save-interval: 6000
  max-auto-save-chunks-per-tick: 8
  prevent-moving-into-unloaded-chunks: true

collisions:
  max-entity-collisions: 2
  fix-climbing-bypassing-cramming-rule: true

entities:
  spawning:
    despawn-ranges:
      ambient: { hard: 72, soft: 30 }
      creature: { hard: 72, soft: 30 }
      monster: { hard: 72, soft: 30 }
  behavior:
    tick-rates:
      sensor:
        villager:
          secondarypoisensor: 40
      behavior:
        villager:
          validatenearbypoi: -1

bukkit.yml & spigot.yml

Controls monster spawn caps and entity activation ranges at the engine level.

# bukkit.yml
spawn-limits:
  monsters: 50
  animals: 8
  water-animals: 3
  water-ambient: 4
  ambient: 1
ticks-per:
  monster-spawns: 4
  animal-spawns: 400

# spigot.yml
world-settings:
  default:
    mob-spawn-range: 6
    entity-activation-range:
      animals: 16
      monsters: 24
      raiders: 48
      misc: 8
    merge-radius:
      item: 3.5
      exp: 5.0

03 // INSTALLATION INSTRUCTIONS

Deploy in under two minutes.

KZOptimizer works immediately out of the box with safe defaults and generates its configuration files on first boot.

STEP 01

Download the JAR

Grab the latest release build of KZOptimizer.jar directly from the official Kaizen Developer GitHub repository.

github.com/kaizendev172/kzoptimizer-plugin →
STEP 02

Upload to Plugins Folder

Stop your Minecraft server cleanly, then place KZOptimizer.jar inside your server's /plugins/ directory. Avoid using /reload.

STEP 03

Start & Verify

Boot your server and run /kz status in console or in-game (requires kzoptimizer.admin) to confirm active telemetry.

CORE COMMANDS /kz status /kz reload /kz gc /kz profile
